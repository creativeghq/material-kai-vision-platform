# MaterialsHub — crawl policy
#
# A crawler obeys ONLY the most specific User-agent group that matches it, and
# ignores every other group. A named group with no Disallow lines is therefore an
# unrestricted crawl, which is what this file granted until 2026-08-10.
#
# The Disallow list below used to be pasted once per named agent. It is now written
# ONCE under a group carrying several `User-agent:` lines — RFC 9309 §2.2.1: "if a
# group contains multiple user-agent lines, the rules apply to all of them". Every
# named crawler we allow shares one policy, so it lives in one place; four copies of
# a 30-line list is four chances for the next addition to reach three of them.
#
# Two things are being kept out of the index here:
#   1. The authenticated app surface. It renders an empty shell to a crawler
#      anyway, so crawling it is pure cost.
#   2. Tokenised share URLs (/q/, /i/, /sheets/, /pay/, /statement/, ...). The
#      token IS the credential; an indexed one is a public document.
#
# This file is advisory. Scanners probing for /wp-login.php and /.env do not
# read it — those are handled by the rewrite exclusions in vercel.json, which
# return a real 404 instead of the 5.5 KB app shell.

# ── Search indexes and answer engines ───────────────────────────────────────────
#
# RETRIEVAL is not TRAINING, and until 2026-08-22 this file did not distinguish
# them: OAI-SearchBot, ChatGPT-User, PerplexityBot and Perplexity-User were blocked
# alongside GPTBot, so the platform was absent from every answer engine by
# configuration — while public/llms.txt sat there addressed to exactly those agents.
# The two files contradicted each other and our own AI visibility was structurally
# zero, which is not something a measurement can detect.
#
# The agents below fetch a page to ANSWER a question a person just asked, or to keep
# a search index that answers cite from. They are read the same way Googlebot is
# read, and they get the same Disallow list. The training crawlers stay blocked in
# the next section — that opt-out is unchanged.
