Settings · Documents

/finance finance.manage

The Documents section is where you set up everything that controls how your invoices, receipts and other documents are numbered, branded and transmitted. It groups five separate jobs onto one screen: your physical branches (establishments), the numbering series for each document type, the visual template applied to every invoice, your card-payment terminals, and the inbox connection that pulls documents your suppliers have issued to you. Get these right once and every document you raise afterwards inherits them.

Where it is

Top navigation → Finance → Settings tab → Documents (in the row of settings sub-tabs).

What's on the screen

Five stacked blocks, top to bottom:

  • Establishments — your registered branches, each with the establishment (branch) number used when transmitting to myDATA.
  • Document Types & Series — the numbering series defined per document type and assigned to a branch.
  • Invoice design template — the visual template ("Classic") plus seven brand colour pickers that style every invoice.
  • EFT-POS Terminals — the card-payment terminals registered for card receipts.
  • myDATA Inbox (Received Documents) — the credentials that let the platform pull documents your suppliers issued to you.

Establishments

An establishment is a physical place of business — a branch. It matters because branches transmit to myDATA under their establishment number, so myDATA can tell which location issued a document. Your headquarters is always branch 0; additional shops, warehouses or showrooms are branches 1, 2, 3 and so on. Once a branch exists you assign a numbering series to it over in Document Types & Series.

How to add an establishment — step by step

  1. Go to Finance → Settings → Documents.
  2. In the Establishments block, click Add establishment. A dialog opens.
  3. Fill in the fields (see the table below).
  4. Leave the Active toggle on so the branch can be used on documents.
  5. Click Save. (Or Cancel to discard.) The new branch appears in the Establishments list, ready to be assigned a numbering series.
FieldWhat to enter
Branch numberThe establishment number that myDATA will recognise. Defaults to 1 for your first added branch (HQ is branch 0).
NameA label to recognise the branch by, e.g. "Store — Athens".
StreetThe branch's street name.
NumberThe street number.
Postal codeThe branch's postal code.
CityThe branch's city.
ActiveToggle. On = the branch can be selected on documents.

Document Types & Series

This block is where you define a numbering series per document type — for example a series for invoices, another for receipts — and assign each series to a branch. This is what produces the running document numbers (and, paired with the establishment number, tells myDATA which branch issued each document). Set up the series you need before you start issuing documents so numbering is consistent from the first one.

Invoice design template

This block controls how every invoice looks. The template is "Classic" — described as "Centered wordmark, thin hairline rules, monochrome." You don't change the layout, but you do brand it with your own colours through seven pickers.

Colour pickerWhat it sets
AccentThe highlight colour used for accents on the document.
Header backgroundThe background of the invoice header band.
Header textThe text colour inside the header.
Table headerThe colour of the line-items table header row.
TextThe main body text colour.
Secondary textThe colour for less-prominent supporting text.
Lines / bordersThe colour of the hairline rules and borders.

How to brand the invoice — step by step

  1. In the Invoice design template block, confirm the template shows Classic.
  2. Click each of the seven Colors pickers (Accent, Header background, Header text, Table header, Text, Secondary text, Lines / borders) and choose the colour you want.
  3. Click Save template to apply your colours to every invoice going forward.
  4. Changed your mind? Click Reset to defaults to put the original monochrome scheme back, then Save again if you want to keep the reset.

EFT-POS Terminals

This block lists the card-payment terminals registered to your business. Until you add one it reads "No terminals registered. Card receipts will transmit without a terminal signature until one is added." — meaning card receipts still go out, just without a terminal signature attached.

How to add a terminal

  1. In the EFT-POS Terminals block, click Add terminal.
  2. Enter the terminal's details and save. Once a terminal is registered, card receipts can transmit with its signature.

myDATA Inbox (Received Documents)

This block connects the platform to your myDATA inbox so it can pull the documents your suppliers issued to you (rather than the ones you issue out). Once the credentials are saved here, the "Sync from myDATA" action can fetch those received documents into the platform.

FieldWhat to enter
User IDYour myDATA user id — sent to the API as the aade-user-id header.
Subscription KeyYour myDATA subscription key — sent as the Ocp-Apim-Subscription-Key header. Entered as a password (masked).
  1. Paste your User ID into the first field.
  2. Paste your Subscription Key into the second (it's masked like a password).
  3. Save. The platform can now run Sync from myDATA to pull your received documents.

Worked example — opening a second shop. You open a store in Athens. Go to Documents → Establishments → Add establishment, set Branch number 1, Name "Store — Athens", fill the address, leave Active on, click Save. Then in Document Types & Series create a numbering series for that branch's invoices and assign it to the new establishment. From then on, invoices raised for the Athens store carry their own running numbers and transmit to myDATA under establishment number 1 — while your HQ documents stay on branch 0.

What this section affects

Everything here is foundational, not cosmetic-only:

  • Document numbering — establishments and the per-type series determine the running number on, and the branch attribution of, every invoice and receipt you issue.
  • Branding on every document — the seven invoice colours apply to all invoices once saved.
  • Received documents — the myDATA Inbox credentials power the "Sync from myDATA" pull of supplier-issued documents.

To see these settings in action on the documents you actually raise, head to Finance → Documents.
