Projects

/projects /projects/:id

Projects are the top-level container for a piece of work — from an interior-design job to a full construction contract. A project ties together the moodboards, sheets, quotes and people involved, delivers a polished online Client View, and — for contracting — carries a whole construction toolset (drawings, RFIs, a programme, tenders, valuations). The detailed areas are on their own pages below.

Seven stages. A project's sections are grouped into seven stages on one row — Overview · Design · Specification · Commercial · Delivery · Client · Review — so a long job stays navigable (see the stages for the full map). You can tag a project with a category (Renovation, Trip, Warehouse, Real Estate, or your own) for filtering; the category is a label, it doesn't change which tools appear.

How to open it: top navigation → Projects (module-gated — if it isn't shown, the Projects module isn't enabled for your workspace). Use New Project to create one; Show archived reveals archived projects.

The projects grid — covers, sorting & a list view

The list is a grid of cover cards with a toolbar (search and filters on the left, sort and a view toggle on the right) and a count band at the foot (“N projects”, and a “show them” toggle for archived ones).

  • Every project wears a cover. The picture is chosen down a ladder: the project's own cover image if you set one, else its newest moodboard image, else a library scene picked from the project's name (a kitchen job gets a kitchen, a bathroom a bathroom). You set or change it from ProjectCover at the top of a project's Overview — pick a moodboard image, a library scene, an upload, or an AI render; “Use automatic” hands it back to the ladder.
  • Card anatomy. A 16:9 cover with the status top-left (and a Shared badge when a project isn't yours), then the category, the name, and the client. Below, a budget bar — spent against budget, turning red when over (or “No budget set”) — and a footer with the moodboard count, accepted-quote count and the deadline (a warning when overdue, or last activity when there's no deadline). The whole card is a link into the project.
  • Sort — Recently active (default), Deadline, soonest first, Name A–Z, Most budget used, or Newest first; projects missing that value sort last. Your choice is remembered.
  • Grid or list. A toggle switches the covers for a dense table (sortable by any column — name, client, status, budget, deadline, boards, quotes, activity), and back. That choice is remembered too.
