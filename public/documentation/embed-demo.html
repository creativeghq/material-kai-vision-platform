Things worth trying

  1. Drag the model. It is the glTF uploaded against that product, served from storage — not a photo. Without a model you get the product's photo instead.
  2. Switch a finish. Only the parts using that glTF material change; a choice targets a material, not the whole model, so picking a fabric leaves the legs alone.
  3. Watch the price. Every change re-asks the server. The widget never adds the numbers up itself, so it cannot disagree with the quote that follows.
  4. Break a rule, if the product has any. The reason appears under the swatches and the cart button refuses — the same check stops it reaching a quote.
  5. Add to cart on a valid combination. The payload appears below; on a real shop that is what your cart receives.

Starting from a spec instead of a product

The widget above answers "show me this". This one answers "I want something like this — what does it cost?", which ends in one of two places. If a published product satisfies every choice, you get its price and the product itself. If nothing does, you get a quote request — and that is the normal outcome, not the error case: a configurator bound to one product can only ever sell what someone already modelled and priced.

Build a spec

Only needs a key — no product id

Things worth trying

  1. Pick nothing and press Price it. An empty spec matches everything, so you get the first published product. Containment with no constraints is not an error.
  2. Pick only values marked ●. Those are values a published product actually carries; the rest is the shared taxonomy. A spec built entirely from ● can still miss — the marks are per value, not per combination.
  3. Mix one ● with one unmarked value. Nothing matches exactly, so you land on the quote form with the close ones listed above it — deliberately without prices, because a near match is a suggestion and not an offer.
  4. Send the quote request. It creates a CRM contact and a quote_requests row carrying your exact spec. No total: nobody has priced it yet, and a number there would anchor the negotiation on a figure that came from nowhere.
