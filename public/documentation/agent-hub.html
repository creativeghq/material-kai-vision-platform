Agent Hub (JARVIS)

/agent-hub

The conversational AI workspace at the centre of the platform. Ask in plain language and the assistant searches, creates, and automates across every module — returning rich, interactive results inline in the chat.

What this page is for

Instead of clicking through menus, you describe what you want — “find 5 cement-based grey tiles for a modern bathroom”, “stage this empty room”, “track the price of this product”, “build a material board from these images” — and the assistant uses the platform's tools to do it. It is the single fastest way to get value from MaterialsHub.

Layout

  • Conversation list (left) — every chat you've had, each with a Search conversations… box. Items can be renamed or deleted, and show the topic/tools they used.
  • Agent selector (above the composer) — switch between the available AI agents: JARVIS, Interior (Interior Designer) and Demo.
  • Composer — type a message; the toolbar adds attachments, documents, voice input, an inspiration-URL analyser, and a tools menu. Shift+Enter inserts a new line.
  • Chat panel — the active conversation, where results render as interactive cards (products, images, search specs, price/mention data, sheets, and more).

The composer & the “/” tools menu

Type / in the message box to launch a workflow or invoke a specific tool directly, rather than relying on the assistant to choose. The composer toolbar exposes the most-used actions:

  • 📎 Attach — add images (e.g. a room photo or material sample) for the assistant to analyse.
  • 📄 Document — attach a document for context.
  • 🎤 Voice — dictate your message.
  • 🌐 Inspiration URL — paste a web page; the assistant extracts its palette, materials and style and finds matching products.
  • Core / + Toolkit — the assistant's available tool set; the toolkit expands as your plan/role unlocks more.

The full catalogue of what the assistant can do is documented in Tools & Capabilities.

An open conversation

Using it — a typical session

  1. Pick an agent (default is JARVIS) and type a request, optionally attaching images.
  2. Watch results stream in as cards; open a product, save it to a moodboard, or continue refining.
  3. Chain follow-ups in the same thread — the assistant keeps the context of the conversation.
  4. Start a new conversation for a new topic, or reopen any past one to continue.

Credits: chatting and searching are inexpensive; explicit generation actions (images, presentation sheets, scans, 3D/VR) consume credits, and the assistant tells you the cost when an action is metered. See Account & Billing.

Where results go: many actions create real artefacts — a moodboard sheet, a tracked price/mention subject, a generated image — that also appear in their own module so you can find them later outside the chat.
