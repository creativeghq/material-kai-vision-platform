Product 3D models

/agent-hub

A product can carry a 3D model — a real mesh of the sofa, chair or lamp that the Room Planner, 3D Rooms and the website embed can show. Models are now generated from a product photo; you no longer upload one by hand.

Making a model for a product

Ask the assistant in the Agent Hub (or call the API) to make a 3D model of a product. Two things decide how good it is:

  • What the object is — say "sofa", "bar stool", "pendant lamp". A product name alone does not tell the model which object in the photo to build, so this is required.
  • Its size (optional, recommended) — width, depth and height. The model always has the real proportions of the photo; a stated size is what makes it the real size too.

The model is built from the product's photo as a GLB mesh and stored on the product. It costs 10 credits, refunded if the generation fails.

Size in the Room Planner. A generated model is placed at its true size only when a size was stated. Without one, the planner uses a 0.60 m placeholder footprint and labels it placeholder, so you never mistake a default for a measurement.

Supplier models

Models that suppliers already provided for their products still display wherever a 3D model is shown. There is no upload screen for new ones — generate them instead.

Furniture inside a 3D room

Furniture in a 3D room is made 3D from your own renders, not from the catalogue photo — see Make 3D on the 3D Rooms page.
