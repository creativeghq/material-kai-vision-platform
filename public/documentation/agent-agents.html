AI Agents

/agent-hub

The Agent Hub offers several specialised assistants. They share the same chat surface and tools, but differ in personality, focus, and which capabilities are emphasised.

Choosing an agent

The selector sits directly above the composer. Switching agent changes the assistant's framing and default behaviour for that conversation; you can start different conversations with different agents.

JARVIS — the default assistant

JARVIS is the general-purpose “Material Intelligence” agent: search, insights, research & content. It's the right choice for almost everything — finding materials and products, answering questions about your catalogue, running price/mention/job research, generating images, and producing content. It has the broadest tool access.

  • Best for: catalogue search, product discovery, research, automation, content.
  • Strength: breadth — it can reach the full toolkit and chain steps together.

Interior Designer

The Interior Designer agent is tuned for spatial and aesthetic work. It leans into the visual tools — building moodboards and presentation sheets, virtual staging, lighting and render workflows, palette and material selection — and frames its responses around design intent (style, mood, room type, finishes).

  • Best for: concept development, room schemes, FF&E selection, client-facing visuals.
  • Strength: design-aware reasoning and the creative/visual toolset.

Demo

The Demo agent is a lightweight assistant intended for quick demonstrations and trying out the chat experience. It's a fast, low-cost way to see how the Agent Hub behaves.

How agents relate to tools

All agents draw from the same underlying tool catalogue. What differs is emphasis and access:

AgentFocusTypical tools emphasised
JARVISGeneral material intelligenceSearch, research (price/mention/jobs), image generation, content, web/manufacturer search
Interior DesignerDesign & visualisationMoodboards, presentation sheets, virtual staging, inspiration-URL, lighting/render
DemoQuick trialCore chat + search

Access & roles: core tools are available to everyone. Some advanced tools (certain research, B2B and SEO capabilities) are gated to higher roles/plans, so the toolkit you see may be larger or smaller than another user's.

Tip: not sure which to pick? Start with JARVIS. Switch to Interior Designer when the task is about how a space should look and feel.
