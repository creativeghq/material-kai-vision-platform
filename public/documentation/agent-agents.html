AI Agents — the roster

/agent-hub

The Agent Hub is staffed by a roster of named agents, each a specialist in one part of the platform. You don't have to know which one to pick: the default agent, JARVIS, is an orchestrator that reads your request and auto-routes it to the right specialist. But you can also pick a specialist directly from the agent switcher when you know exactly whose job it is. This page introduces each agent, what it's for, and how the auto-routing works.

How to choose an agent

  1. Open Agent Hub and click New Conversation.
  2. Above the message box, open the agent switcher (a dropdown). Leave it on JARVIS (Auto-assign) to let it route for you, or pick a specialist.
  3. Type your request. With JARVIS, it's handed to whichever specialist owns the task; with a specialist selected, that agent handles it directly.

Why auto-assign helps: most requests don't map cleanly to one “mode” in your head — you just want the outcome. JARVIS looks at what you asked and dispatches it (a design request goes to Vision, a finance/quote request to Trinity, and so on), so you get the right tool without choosing it. Pick a specialist yourself only when you want to stay in one lane.

Each specialist carries only the tools for its area, which is what makes its answers focused. The full catalogue of what any agent can do — described as tasks, not tool names — is on Tools & Capabilities.

Coming soon — Stark & Veritas

Two more agents appear in the switcher as disabled “Coming soon” teasers: Stark — an autonomous build agent that writes, runs and ships changes in a sandbox — and Veritas — a QA & code-review agent that verifies, tests and audits work. They need a sandboxed execution tier that isn't switched on yet, so you'll see them listed but can't select them.

Tip: stay on JARVIS for almost everything and let it route. Reach for a specialist (e.g. Vision for a full design session, Trinity for a quoting session) when you want a focused, single-topic thread.
