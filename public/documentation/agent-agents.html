AI Agents (Modes)

/agent-hub

The Agent Hub runs several distinct agents (modes). They share the same chat window but have different jobs, different toolsets, and even different underlying models. Picking the right one changes what the assistant can actually do for you. This page explains each agent: what it is, who it's for, exactly what it can do, a real example workflow, and what results you get back.

How to switch mode

  1. Open Agent Hub from the top navigation and click New Conversation.
  2. Above the message box, click JARVIS, Interior or Demo.
  3. Type your request. The mode you picked decides which tools the assistant may use for that conversation — you can keep one thread on JARVIS and another on Interior at the same time.

Why the mode matters: each agent is given a different set of tools. JARVIS can search, research, monitor and automate; the Interior Designer can generate 3D rooms, relight images and build presentation sheets. Ask the Interior agent for an SEO audit and it won't have that tool; ask JARVIS to relight a room and it won't have that one. Match the mode to the job.

1. JARVIS — the material-intelligence agent (default)

What it is — the general-purpose powerhouse, branded JARVIS (internally the “KAI” agent). It runs on a top-tier model and has by far the widest toolset. Who it's for — everyone, for almost everything: finding materials, researching, monitoring, and producing content. If you're unsure which mode to use, use this one.

What it can do (and what you get back)

  • Search your catalogue — material search, visual search and a knowledge-base search. Result: product cards (and an explainable “search spec” card showing the colours/materials/styles it matched on).
  • Analyse an inspiration URL — paste a web page; it extracts the palette, materials and style and finds matching products. Result: an inspiration card + product matches.
  • Free calculators — heat-pump sizing and heating-cost comparison, answered inline.
  • Price & mention monitoring — start tracking a product's price or a brand's mentions, pull a summary, check “LLM visibility” (whether AI assistants recommend it), and surface negative mentions. Result: tracked subjects + summary cards (see Tools & Capabilities).
  • Job research — set up a recurring job search, list your searches, fetch matches, preview the daily digest.
  • A full SEO suite — keyword research/difficulty/intent/volume, SERP & URL audits, domain snapshots, ranked keywords, competitor & keyword-gap analysis, backlinks, site crawls, content sentiment, Google Trends, YouTube/Amazon/Reddit/Pinterest/Trustpilot search, brand-search and site-review audits — and an end-to-end SEO article pipeline (research → plan → write → analyse).
  • B2B research (admin/owner) — manufacturer web search, website scrape, company enrichment, contact discovery, email validation, and save-to-CRM.
  • Presentation catalogs (admin/owner) — create a catalog, attach/extract from PDFs, translate a PDF into a catalog, add materials, generate the catalog PDF and publish it.
  • Projects & sales admin — create a project and add tasks; create trip cards and log sales-trip expenses (see Sales).

Example. Type: “find 5 matte grey porcelain tiles for a hotel bathroom, then start tracking the cheapest one's price.” JARVIS runs a material search (returns product cards + a search-spec card), you pick one, and it sets up price monitoring on it — all in the same thread.

Note on access: the core tools (search, inspiration-URL, calculators, monitoring, jobs, projects) are available to everyone. The B2B, catalog and some SEO-article tools are gated to admin/owner roles — JARVIS simply won't offer those if your role doesn't allow them.

2. Interior Designer — the design & visualisation agent

What it is — a design-focused agent (runs on the most capable model for design reasoning). It thinks in terms of space, style and finishes, and — crucially — it has the image-generation and image-editing tools that JARVIS doesn't. Who it's for — interior designers and anyone turning a room or a brief into visuals and a client-ready scheme.

What it can do (and what you get back)

  • Find materials for a scheme — material search framed around style/mood/room type. Result: product cards.
  • Generate a 3D room / design (generate_3d) — produces a rendered design; runs asynchronously and returns a job that fills in when ready. Result: a generated room image.
  • Re-light a room (the “edit”) (apply_lighting_preset) — take a room image already in the conversation and re-render it under a chosen lighting preset (daylight, golden hour, evening, showroom, night…). Result: the same room under different lighting, so you can show a client how a space reads at different times.
  • Region Edit (edit one area only) — open the full-screen mask painter, paint over a zone of a room image (e.g. just the floor or one wall), describe the change, and regenerate only that region. Result: a precise edit with the rest of the image untouched.
  • Build a VR walkthrough (generate_vr_world) — turn a room image into an explorable 3D world you can embed in a project's Client View.
  • Analyse an inspiration URL — same palette/material/style extraction as JARVIS, to seed a scheme from a reference.
  • Produce presentation sheets (generate_presentation_sheet) — material boards, colour palettes, lighting plans, annotated renders, FF&E schedules, area breakdowns, full decks (see Presentation sheets).
  • Organise the work — create a project and add tasks so the scheme has a home.

Example: a full Interior Designer workflow

  1. Switch to Interior, attach a photo of the empty room (or describe it).
  2. Ask it to generate a 3D design in a given style — it returns a rendered room.
  3. Ask it to apply an “evening / warm” lighting preset to that render — it returns the relit version (the editing step).
  4. Ask for matching materials — product cards you can save to a moodboard.
  5. Ask it to generate a VR walkthrough and an FF&E / area-breakdown sheet.
  6. Bundle the render, the VR world and the sheets into a Client View for the client.

The image-driven tools (lighting preset, VR world) need a room image already in the conversation — generate or attach one first, then ask to edit it.

3. Demo — the showcase agent

What it is — a lightweight showcase mode for demonstrating the chat experience quickly and cheaply. Who it's for — trying things out or showing someone how the Agent Hub feels before committing to real work. It has no specialised tools and is intended for admins/owners running a demo.
