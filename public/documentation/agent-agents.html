AI Agents

/agent-hub

The Agent Hub offers several specialised assistants. They share the same chat surface and the same underlying tools, but differ in personality, focus, and which capabilities they emphasise. This guide explains what each agent is, why it exists, and — most importantly — when to use which.

Choosing an agent

What it is — the agent selector sits directly above the composer. Why it matters — switching agent changes the assistant's framing and default behaviour for that conversation, so the choice shapes how it interprets and answers you. How: click the selector, pick the agent that fits the task, then type your request. You can start different conversations with different agents, so it's fine to keep one thread on JARVIS and another on Interior.

1. JARVIS — the default assistant

What it is — JARVIS is the general-purpose “Material Intelligence” agent: search, insights, research & content. It has the broadest tool access and can chain steps together. Why it matters — it's the right choice for almost everything, which means you rarely have to think about agent selection at all.

  • Best for: catalogue search, product discovery, research, automation, content.
  • Strength: breadth — it can reach the full toolkit and chain steps together.

When to use it: finding materials and products, answering questions about your catalogue, running price/mention/job research, generating images, and producing content. If you're unsure which agent to pick, start here.

2. Interior Designer

What it is — an agent tuned for spatial and aesthetic work. It leans into the visual tools — building moodboards and presentation sheets, virtual staging, lighting and render workflows, palette and material selection — and frames its responses around design intent (style, mood, room type, finishes). Why it matters — design-aware framing produces answers that think about how a space looks and feels, not just which items match keywords.

  • Best for: concept development, room schemes, FF&E selection, client-facing visuals.
  • Strength: design-aware reasoning and the creative/visual toolset.

When to use it: switch to Interior Designer when the task is about how a space should look and feel — developing a concept, putting together a room scheme, selecting FF&E, or preparing visuals for a client.

3. Demo

What it is — a lightweight assistant intended for quick demonstrations and trying out the chat experience. Why it matters — it's a fast, low-cost way to see how the Agent Hub behaves before committing to real work. When to use it: when you just want to explore or show someone how the chat works.

How agents relate to tools

All agents draw from the same underlying tool catalogue. What differs is emphasis and access — the table below summarises the focus and the tools each agent tends to reach for.

Access & roles: core tools are available to everyone. Some advanced tools (certain research, B2B and SEO capabilities) are gated to higher roles/plans, so the toolkit you see may be larger or smaller than another user's.

Tip: not sure which to pick? Start with JARVIS. Switch to Interior Designer when the task is about how a space should look and feel.
