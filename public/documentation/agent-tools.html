Tools & Capabilities

This is the full catalogue of what the assistant can actually do — every tool, what it's for, and what it returns. You rarely name a tool: describe the outcome and the assistant picks it (or type / to choose one). Which tools are available depends on the agent mode and your role/plan.

How to read this: tools are grouped by job. The “Returns” column tells you what appears in the chat. Tools tagged admin/owner are only offered to those roles; everything else is available to all signed-in users. Generation actions that cost credits say so at the point of use.

Invoking tools

  • Natural language — describe the outcome; the assistant chooses the tool.
  • “/” menu — type / in the composer to run a specific tool/workflow directly.
  • Composer buttons — attachments, voice and the inspiration-URL analyser are one click away.

Availability varies by mode, role & plan. The Interior tools (3D, lighting, VR) exist only in Interior Designer mode; B2B, catalog and SEO-article tools require admin/owner; module-gated tools (price/mention/job monitoring) need the relevant module enabled for your workspace.
