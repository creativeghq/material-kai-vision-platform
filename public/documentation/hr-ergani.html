HR · Ergani filing owner / admin · BYOK

/hr

Greek employers must file employment events — hires, work schedules, overtime, departures, leave and attendance punches — to the labour authority's ΠΣ Εργάνη (Ergani) system. HR connects directly to the Ergani II Web API so those filings happen from inside the platform: an employee clocking in at the kiosk, or a leave you approve, is submitted to Ergani and comes back with an official protocol number. This is a bring-your-own-key (BYOK) integration — it uses your company's Ergani Web API credentials, because filings are made under your employer identity. This page covers exactly what to add, where, and what gets filed.

These are special Ergani Web API credentials — not your normal Ergani/ΕΦΚΑ web login. You obtain a dedicated API username and password for your employer (ΑΦΜ) from the Ergani Web API registration, and enter them here. Filings are made as your company, so the credentials must be your own.

Step 1 — Get your Ergani Web API credentials

From the Ergani side (outside MaterialsHub) you'll need four things for your employer:

  • An Ergani Web API username and password — the API credential pair issued for your employer's account (distinct from the interactive Ergani portal login).
  • Your Employer VAT (ΑΦΜ) — the 9-digit tax number of the employing company (e.g. 094187530).
  • Your Branch number (Παράρτημα) — the establishment/branch the filings are for (the head office is typically branch 0).

Where: open Profile → Keys and fill the Ergani credentials card. (HR → Ergani shows your connection status and links straight here when nothing is configured yet.)

What gets filed to Ergani

Once connected, HR files the events Ergani requires — each successful submission returns a protocol number and submit date that HR records against the item, so you have proof it was lodged:

EventHow it's triggered
Attendance punches (arrival / departure)Every clock-in / clock-out at the kiosk or the employee portal is filed; the row then shows Ergani ✓ with its protocol. (Manual correction punches are not filed.)
Leave / time-offWhen you approve an absence you can File leave to Ergani, choosing the matching Ergani leave type (an official leave code — see below). See Time-off.
Ε3 — Hire announcement (αναγγελία πρόσληψης)HR → Employees: each person shows a File Ε3 action, prefilled from their employee record. Once filed the row shows the protocol instead.
Ε4 — Work schedule (πίνακας ωρών εργασίας)HR → Schedules: build a weekly roster (or copy the employee's contract hours), then file it. Weekly rosters file as WTOWeek, daily ones as WTODaily, and an amendment to a roster Ergani already holds as WKChgWK.
Ε5 / Ε6 / Ε7 — DeparturesHR → Departures: record a voluntary departure (Ε5), a contract termination (Ε6) or a fixed-term expiry (Ε7) — the document is chosen from the departure type, never by hand. Filing also marks the employee as terminated and sets their end date.
Ε8 — Overtime (αναγγελία υπερωρίας)HR → Overtime: log the hours worked beyond the schedule (a reason is required — Ergani rejects a declaration without one), tick the entries you want, and file them together as a single Ε8.

Review before you file

Ergani publishes the exact field layout of each document only inside its own samples pack, and it differs from employer to employer. So rather than guessing, MaterialsHub fetches your employer's own live template for the document and fills in the fields it recognises from your records. Anything it can't match is listed for you at the top of the filing window.

That's why every filing opens a review step: you see exactly what will be sent, complete anything left blank, and only then submit. Values you fill in repeatedly for the same person — their specialty code, contract type — can be saved onto the employee so they prefill next time. Nothing is sent to the authority until you press File.

Once a schedule, departure or overtime entry has been filed, it becomes read-only — the filed copy belongs to the authority, so editing ours would put the two out of step. Cancel it in Ergani first if it needs to change.

Ergani leave types

Ergani classifies leave by an official code (each with a Greek and English description, a category/subcategory, and whether it's hourly). When you file a time-off, you map your absence to the right Ergani leave code so the authority records the correct category. HR loads the current list of leave types for you to pick from.

Why this matters

Filing from inside HR means the compliance step isn't a separate, forgettable task in another portal — the moment someone clocks in or you approve leave, it's lodged and stamped with a protocol. Because it's BYOK, every filing is correctly attributed to your employer account, and one workspace can never file under another's identity.
