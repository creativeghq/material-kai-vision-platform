Settings · Pricing

/finance finance.manage

The Pricing section lets you set Category Markup Rules — per-category percentages that turn a catalogue product's cost into its sell price automatically when you add it to a document. Set a rule once per category and every product in that category gets priced consistently, without you doing the maths each time.

Where it is

Top navigation → Finance → Settings tab → Pricing (in the row of settings sub-tabs).

What's on the screen

The panel is headed Category Markup Rules. To create a rule you give it two things and add it:

  • Category — the product category the rule applies to. You pick this from the existing product categories.
  • Markup % — the percentage added on top of the catalogue cost to arrive at the sell price (for example, 25).
  • Add — saves the rule so it applies to that category from then on.

How to add a markup rule — step by step

  1. Go to Finance → Settings → Pricing.
  2. Pick the product Category the rule should cover.
  3. Enter the Markup % — for example, type 25 for a 25% markup.
  4. Click add to save the rule. It now applies to every catalogue product in that category.
  5. Repeat for each category that should have its own markup.

Worked example — pricing a category at 25%. Open Pricing → choose the category (say, "Tiles") → enter 25 in Markup % → click add. From now on, when you pick a tile onto a quote or invoice, its sell price is its catalogue cost plus 25% — calculated for you the moment you add it.

What it affects

A Category Markup Rule converts a catalogue product's cost into a sell price at the point you pick that product onto a document (a quote, invoice or receipt). For products in a category that has a rule, that rule's percentage is used and it overrides the Default catalog markup % set in General. Categories without a rule fall back to that General default. Changing a rule affects future documents — products already added to existing documents keep the price they were given at the time.
