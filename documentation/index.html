MaterialsHub — User Documentation

A page-by-page guide to the MaterialsHub platform: what each screen does, how it works, and what you can accomplish from it.

MaterialsHub is an AI-powered platform for the materials, design, and construction industry. It brings together a searchable material knowledge base, an AI assistant, moodboards, quotes, a full finance & invoicing suite, CRM, a discovery marketplace, and a set of free tools — all inside a single workspace.

How to read this guide. The left sidebar follows the same structure as the app's top navigation. Each page documents one area: a screenshot of the live screen, what it's for, the controls available, and step-by-step actions. Screenshots are taken from the live application.

Quick start

New to the platform? Start with Getting Started for sign-in, workspaces, roles, navigation, and how credits work. Then explore the Dashboard and the Agent Hub, which is the fastest way to get value from the platform.
