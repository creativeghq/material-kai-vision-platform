Agent Hub (JARVIS)

/agent-hub

The conversational AI assistant at the centre of the platform. Ask in plain language and it searches, creates, and automates across every module.

What this page is for

The Agent Hub is a chat workspace where you talk to the AI assistant. Instead of clicking through menus, you describe what you want — “find 5 cement-based grey tiles for a modern bathroom”, “translate this PDF catalogue”, “track the price of this product” — and the agent uses the platform's tools to do it, returning rich, interactive results inline in the chat.

Layout

  • Conversation list (left) — every chat you've had, with a Search conversations… box. Each item can be renamed or deleted, and shows the agent/topic it used.
  • Chat panel (right) — the active conversation, the message composer, and any attachments or results.

What the assistant can do

The agent has access to a broad toolset. Among the things you can ask for:

  • Material & product search — multi-vector search across the catalogue, with an explainable “search spec” (colours, materials, style, specifications).
  • Image generation & editing — create or restyle visuals, virtual staging with before/after comparison.
  • Inspiration from a URL — paste a web page and it extracts the palette, materials and style, then finds matching products.
  • Moodboard presentation sheets — generate client-ready sheets (material boards, color palettes, lighting plans, FF&E schedules, full decks).
  • Price monitoring — track a product's price across retailers and get alerts.
  • Mention monitoring — track where a brand/product is mentioned across news, blogs and even AI answers.
  • Job research — set up a recurring job-discovery search with a daily digest.
  • Web / manufacturer search and general Q&A about your catalogue.

Using it

  1. Type a request (you can also attach images) and send.
  2. Watch results stream in as cards; click through to open materials, save to a moodboard, or continue the task.
  3. Start a new conversation for a new topic, or reopen an existing one to continue where you left off.

Credits: chatting and searching are inexpensive, but explicit generation actions (images, sheets, scans, 3D/VR) consume credits. The agent tells you the cost when an action is metered.
