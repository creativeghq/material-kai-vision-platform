# API documentation — where each API is described

The platform exposes three HTTP surfaces. Each has ONE authoritative description, and two of the
three are generated, so they cannot fall behind the code. This page only says where to look.

| Surface | Base URL | Authoritative description | How it stays current |
|---|---|---|---|
| **MIVAA** (Python / FastAPI: ingestion, products, images, embeddings, search) | `https://v1api.materialshub.gr` | Swagger UI [`/docs`](https://v1api.materialshub.gr/docs) · ReDoc [`/redoc`](https://v1api.materialshub.gr/redoc) · [`/openapi.json`](https://v1api.materialshub.gr/openapi.json) | Generated by FastAPI from the running code on every deploy. `GET /` reports the version and the number of documented operations. |
| **Edge functions** (Supabase / Deno: finance, CRM, HR, agents, webhooks…) | `https://bgbavxtjlbvgplozizxu.supabase.co/functions/v1/<name>` | Swagger UI `/api/edge-swagger.html` on the app · [`public/api/openapi-edge.json`](../public/api/openapi-edge.json) | Built from [`scripts/edge-endpoints.json`](../scripts/edge-endpoints.json) by `npm run openapi:edge` (part of `gen:all`). [`tests/unit/openapiSpec.test.ts`](../tests/unit/openapiSpec.test.ts) fails the build when the spec is stale, a function has no entry, a dispatched `action` is undocumented, or a documented action no longer exists. |
| **Market price** (public, keyless) | edge function `public-price` | [`public/api/openapi-price.yaml`](../public/api/openapi-price.yaml) | Hand-written; one endpoint, checked against `supabase/functions/public-price`. |

Database access (`/rest/v1`) for API-key holders is described inside the edge spec, generated from
[`scripts/rest-endpoints.json`](../scripts/rest-endpoints.json).

## Authentication

- **User session:** `Authorization: Bearer <Supabase JWT>`.
- **API key:** `Authorization: Bearer kai_…` — acts as the user who created it, in the one workspace it is bound to. Created in Profile → API keys. Never passes a platform-operator gate.
- **Cron / internal:** `x-cron-secret` or the platform key; not for external callers.
- **Webhooks:** each provider's signature header, verified before processing.

Every route enforces its own workspace and capability checks; the gateway does not do it for them.

## Search, in one paragraph

`POST /api/rag/search` (MIVAA) with the default `strategy=multi_vector` ranks products on text,
visual (SigLIP2 768D), understanding, colour, texture, style, material (Voyage 1024D) and page
vectors. Query understanding (Claude Haiku) chooses the weight profile; the filters it infers are
applied only for `strategy=material`, because as hard filters they emptied one text search in
seven. Single-aspect image matching is `POST /api/search/by-{color|texture|style|material}`.
