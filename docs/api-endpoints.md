# MIVAA API endpoints

This page used to list MIVAA's endpoints by hand. By November 2026, 48 of the 111 paths it named
no longer existed, so it was retired in favour of the reference the code generates itself:

- Swagger UI: https://v1api.materialshub.gr/docs
- ReDoc: https://v1api.materialshub.gr/redoc
- Raw schema: https://v1api.materialshub.gr/openapi.json

For the edge-function API, authentication and the feature guides, see [api-docs.md](api-docs.md).
