Bug Fixes Applied (Jan 17, 2026)

1. YOLO Bounding Box Format Fix

Fixed YOLO layout detector to support both coordinate formats: xmin/ymin/xmax/ymax AND x1/y1/x2/y2. Previously returned degenerate 0,0,0,0 boxes because the actual YOLO API uses x1/y1/x2/y2 format.

2. Page Detection Substring Fallback Removed

Removed substring matching fallback in product page detection. Previously caused false positives: ONA matching 30+ pages (internacional, tradicional, emocional), LOG matching 16+ pages (catalogo, dialog). Now uses word-boundary regex only.

3. Physical Page Count (0-Based Indexing)

Changed from 1-based to 0-based page counting. Cover page is now page 0, giving correct total of 141 physical pages (was incorrectly showing 140). Spread detection remains automatic via aspect ratio.
