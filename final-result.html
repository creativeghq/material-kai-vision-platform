Similar Materials (Embedding Search)

The ProductDetailModal includes a Similar Materials component that uses embedding-based similarity search to find visually similar products.

How It Works

  • 🔍 Uses CLIP embeddings (1024D) for visual similarity
  • 🎨 Uses SLIG embeddings (768D x 4) for specialized matching
  • 📊 Compares color, texture, style, and material properties
  • 🎯 Returns top 10 most similar materials

Embedding Types

  • clip_1024General visual similarity
  • color_slig_768Color palette matching
  • texture_slig_768Surface texture similarity
  • style_slig_768Design style matching
  • material_slig_768Material type similarity

ProductDetailModal Integration

The <SimilarMaterials materialId={product.id} limit={10} /> component queries the Supabase database using pgvector cosine similarity to find materials with embeddings closest to the current product. Results are displayed as clickable cards that open the selected material's detail modal.

Technical Fixes Applied

Image Classification Category Mapping Fix (Jan 26, 2026)

1. Category Mapping Implementation

Added explicit category mapping for Qwen image classification. The AI model returns categories like PRODUCT_IMAGE, MIXED, DECORATIVE, TECHNICAL_DIAGRAM but old code checked for legacy values like material_closeup, material_in_situ.

2. Material Categories Definition

Defined MATERIAL_CATEGORIES = {'PRODUCT_IMAGE', 'MIXED'} as images showing the actual material product. NON_MATERIAL_CATEGORIES = {'DECORATIVE', 'TECHNICAL_DIAGRAM'} are filtered out from embedding generation.

3. is_material_classification() Function

New helper function that properly maps Qwen's classification output to boolean is_material flag. Returns True for PRODUCT_IMAGE and MIXED categories.

4. Endpoint Registry Usage

Updated Qwen and Chandra managers to use the warmed-up endpoint registry for faster processing. Added scale_to_max() call for Qwen batch processing throughput.

Result: 50% Image Retention Rate

Before fix: 0 material images (100% incorrectly filtered). After fix: 35 material images from 70 extracted (50% correctly classified as product images).

SLIG Embedding Fix (Jan 19, 2026)

1. Image Input Parameter Fix

Changed from using raw image_data (base64 string) to using pil_image parameter. The SLIG client expects PIL Image objects for processing, not raw bytes.

2. Method Name Correction

Fixed method call from non-existent get_similarity() to the correct calculate_similarity() method in the SLIG client.

3. Return Type Handling

Fixed return type expectations: SLIG methods return lists directly [...], not dicts with an "embedding" key {"embedding": [...]}.

Result: SLIG Specialized Embeddings Working

All 4 specialized embeddings now generate correctly: color_slig_768, texture_slig_768, style_slig_768, material_slig_768 (4 x 768D each)
